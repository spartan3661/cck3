# Console CCK3+
## Overview
This project is a simple console gui based implementaion of the rogueline CCK3+ as part of coursework for CS 246. This project focuses on basic aspects of C++
such as inheritance, design patterns, RAII, etc.
This project is not complete.

## Installation
To run the project clone the repo
```
git clone https://github.com/spartan3661/cck3.git
```
Then run the makefile to compile the program.
